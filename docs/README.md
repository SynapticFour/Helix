# Helix documentation

Every document under `docs/`, grouped as a tutorial, how-to guides, reference, and explanation. One line each.

Helix is the HelixTest engine as a `helix` binary. Signed evidence stays in HELIOS. A result is not GA4GH certification. See [TRUST.md](TRUST.md).
